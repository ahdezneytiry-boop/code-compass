你马上会看到的代码 · 不用背下来
def greet(name):
    return "你好，" + name

message = greet("小林")

“函数”是什么意思？

给一组步骤起个名字，需要的时候再叫它做一次。这里的 greet 就负责拼出一句问候。

内容保存在你的电脑里 · 当前练习不运行代码
