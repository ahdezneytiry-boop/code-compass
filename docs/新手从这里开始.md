# 知码：从下载到第一次看懂代码

你只需要一台 Windows 电脑。跟着下面做，不需要会编程。

## 先认清三个东西

| 名字 | 你可以怎样理解 |
| --- | --- |
| VS Code | 一个阅读、修改代码的软件，像专门写代码的笔记本。 |
| 知码 | 安装在 VS Code 里面的小助手，帮你解释词语、保存读书笔记。 |
| 练习项目 | 已经准备好的一小组代码文件，你不需要自己写。 |

## 一、安装（推荐方法，不用输入命令）

1. 找到下载的 **知码-0.3.0-新手使用包.zip**。
2. 在这个文件上点鼠标右键，选择 **全部解压缩**。选一个容易找到的位置，例如桌面。
3. 打开解压后的文件夹，双击 **01-install.cmd**。它会打开“知码 · 安装与开始”窗口。
4. 如果窗口说“没有找到 VS Code”，点 **下载 VS Code**。在官网选择 Windows 安装包，安装完成后重新双击 **01-install.cmd**。
5. 点击 **安装知码**，等到窗口明确显示 **安装成功**。已经安装过这一版时会直接告诉你无需重复安装。
6. 点击 **打开练习**。接下来的操作都在 VS Code 里做。

**成功的样子：** VS Code 打开了“练习项目”文件夹；左侧可能出现罗盘形的“知码”图标。知码的新手页通常会自动打开。

不要在压缩包里面直接运行安装助手。`.vsix` 是交给 VS Code 使用的安装包，你不需要解压它。

### 如果双击安装助手没有打开

使用下面的备用方法即可，不需要修改 Windows 的安全设置或关闭防护：

1. 打开 VS Code。
2. 同时按 **Ctrl + Shift + X**，进入“扩展”页面。
3. 在这个页面上方找到 **…**，点击 **从 VSIX 安装…**（英文为 Install from VSIX）。
4. 选择使用包中的 **code-compass-zh-0.3.0.vsix**，等待安装完成。
5. 如果出现 **重新启动扩展** 或 **重新加载窗口** 按钮，点击它。若有未保存的文件，先保存。
6. 点击菜单 **文件 → 打开文件夹**，选择使用包中的 **练习项目**。

安装方式依据 VS Code 官方的扩展安装功能：[官方说明](https://code.visualstudio.com/docs/configure/extensions/extension-marketplace)。

## 二、找到“从这里开始”

如果没有自动看到引导页：

1. 同时按 **Ctrl + Shift + P**。
2. 屏幕上方出现一个搜索框。在里面输入 **知码**。
3. 点击 **知码：从这里开始（一步一步）**。

这个搜索框叫“命令面板”，你只要知道它能帮你找操作就够了。

## 三、一次完成一小步

### 第一步：准备练习

已有“练习项目”的话，新版会自动进入 **2 读懂一句**，不用再创建。也可以点击顶部步骤随时返回。

如果还没有练习，点 **创建我的练习** → 选择桌面或其他位置 → 点 **把练习放在这里**。新窗口打开后，在新窗口里继续。原来的项目不会被覆盖。

### 第二步：读懂一句

点 **打开这几行练习代码**。旁边会出现 `hello.py`。

将鼠标停在 `def` 上，稍等片刻。你会看到“函数定义”的中文解释。再试试 `return`。

这段代码的意思是：**把一个名字交给 greet，它就拼出“你好，某某”。** 不需要运行，也不需要先装 Python。

成功后点 **我完成了，下一步**。这个按钮表示“我已经试过了”，不是程序自动判断你学会了。

### 第三步：写下自己的理解

点 **为练习代码写笔记**。知码会打开练习并选中一段代码。

输入：**这段代码负责拼出一句问候。** 然后按回车。

在左侧“我的笔记”里能看到这句话，说明成功了。笔记不会变成源码里的注释。

以后自己操作时：用鼠标拖动选中代码 → 在选中处点右键 → **知码：给这段代码写笔记**。

### 第四步：试着改错

点 **打开改错练习与对比**。这份练习故意少写了一个冒号。

- 左边：改之前。
- 右边：建议改成的样子。
- 点 **应用修复**：改动才进入编辑器。
- 按 **Ctrl + S**：把改动保存到文件。
- 想退回：按 **Ctrl + Z**。

如果已经修过，再点时显示“没有可确定的自动修复”是正常的，不是安装失败。

## 四、把笔记带走：备份和恢复

“备份”就是另外存一份。换电脑、移动项目文件夹之前做一次，就更容易找回笔记。

### 先存一份备份

1. 在 VS Code 打开原来的项目文件夹。
2. 同时按 **Ctrl + Shift + P**，输入 **知码：备份我的笔记**，点击这个操作。
3. 选择保存位置，例如桌面，点击 **保存笔记备份**。文件名可以保留默认值。
4. 看到 **已备份 X 条笔记**，说明完成。到刚才的位置能找到一个名字包含“知码笔记”的文件。

备份里有你的笔记和当时选中的代码片段。它不是整个项目的备份；请把项目文件夹也一起复制到新位置。修复历史不包含在笔记备份中。

### 再把备份恢复回来

1. 在新位置的 VS Code 里，先用 **文件 → 打开文件夹** 打开代码项目。
2. 按 **Ctrl + Shift + P**，搜索 **知码：从备份恢复笔记**。
3. 选择之前保存的“知码笔记”文件。
4. 如果打开了多个项目，选择本次要放入笔记的项目。只有一个项目时会自动选中它。
5. 如果提示同一条笔记有不同内容，选择 **保留现在的笔记，跳过冲突**，或 **两份都保留**。
6. 看清“恢复到”的文件夹和数量，点击 **确认恢复**。
7. 看到 **恢复完成**，打开左侧知码 → **我的笔记** 查看。

**“跳过”是什么意思？** 这一条没有再次保存。可能本来已有相同内容，也可能没有找到对应代码文件。提示里会分开说明；原来的备份文件不会被删除。若提示文件不存在，先把代码复制到对应子文件夹，再恢复一次。

**“需要重新选择对应代码”是什么意思？** 笔记文字还在，只是代码已改变或出现了两段一样的内容。打开对应文件，选中正确片段，然后在笔记上右键 → **重新选择笔记对应的代码**。

**两个窗口都在写同一条笔记怎么办？** 后保存的窗口会提醒你。它会把你刚输入的文字放到旁边的草稿里；从“我的笔记”重新打开最新内容，再复制草稿中需要保留的部分。不要直接关闭还需要的草稿。

笔记备份一次处理一个项目，最多 5000 条、10 MB。大多数入门练习远小于这个范围。

## 五、卡住时对照这里

| 你看到的情况 | 接下来做什么 |
| --- | --- |
| 没有“知码”图标 | 按 Ctrl+Shift+P 搜索“知码：从这里开始”。仍搜不到，就回扩展页检查是否已安装、已启用。 |
| 提示“请选择工作区内的文件” | 用“文件 → 打开文件夹”打开整个练习项目，不是只双击某一个文件。 |
| 鼠标停上去没解释 | 先试 `hello.py` 里的 `def`；确认右下角显示 Python，且知码提示没有暂停。普通自定义名字可能没有词条。 |
| 不懂“函数、接口、工作区”等词 | 点击“还有词看不懂，查一查”，输入中文或英文。也可打开旁边的《常见词白话表》。 |
| 笔记显示“需重新绑定” | 原代码变了，或有两段一样的文字。选中正确代码，在笔记上右键 → 重新选择笔记对应的代码。 |
| 出现信任文件夹提示 | 只对你自己创建或确认来源的练习选择信任。知码读代码本身不要求运行文件。 |
| 看不懂红色 / 灰色波浪线 | 先看“哪里出了问题”。没有把握时不用急着改；当前版只能自动处理少量明确错误。 |
| 安装一直没成功 | 查看解压文件夹里的“安装结果.txt”，或使用“从 VSIX 安装”的备用方法。 |
| 关闭后笔记还有吗 | 同一个电脑、同一个工作区里会保留。移动项目或换电脑不一定能自动找回，先备份。 |

## 六、目前做不到的事

当前版可以读代码、解释词语、写笔记和提示少量错误。还不能运行 Python、自动画完整调用图、与 AI 聊天或同步团队笔记。按钮不会假装这些功能已经存在。

你不需要阅读 API、数据库结构或开发任务文档就能使用本版。那些文档留给继续开发插件的人。
