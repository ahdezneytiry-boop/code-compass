# 知码 · 中文代码导读

一个本地运行的 VS Code 学习辅助插件。面向 Python / HTML 初学者，帮助读懂术语、代码职责和常见错误，并把自己的理解保存为独立标注。

**首版 v0.1.0 · MVP。无需后端、Python 环境、账号或 API Key。源码默认不上传，插件不会运行你的项目代码。**

## 安装：直接使用安装包

1. 安装 VS Code **1.85 或更新版本**。
2. 打开扩展页面（`Ctrl+Shift+X`），点右上角 `…` → **从 VSIX 安装…**。
3. 选择本目录中的 `code-compass-zh-0.1.0.vsix`，按提示重新加载窗口。
4. 用 VS Code 的 **文件 → 打开文件夹** 打开自己的项目，或者本目录的 `examples` 文件夹。
5. 点击左侧活动栏的 **知码** 罗盘图标，打开 `.py` 或 `.html` 文件。

也可以在命令行安装：

```powershell
code --install-extension .\code-compass-zh-0.1.0.vsix
code .\examples
```

不要只打开一个游离的文件：为了明确文件访问和标注归属，自动分析仅作用于已打开工作区中的文件。VS Code 多根工作区同样可用。

## 五分钟体验

1. 打开 `examples/backend/auth_service.py`，悬停 `def`、`return`、`if`，查看中文解释和例子。
2. 查看“健康提示”：`create_profile` 有参数过多和未读取变量两条提示。点击定位，悬停条目阅读重构建议。
3. 选中一段函数，右键 → **知码：添加标注**。标注出现在侧栏与代码左侧，源码内容不变。
4. 在原代码前插入一行空白：唯一匹配的标注会重新定位。修改所标注的代码：条目会显示“需重新绑定”。选中正确代码，在标注条目的右键菜单中重新绑定。
5. 打开 `examples/practice/missing_colon.py`（故意含有错误），右键 → **知码：预览当前文件安全修复**。查看左右修改对比，再点 **应用修复**。文件不会自动保存，可以用 `Ctrl+Z` 撤销。
6. 打开 `examples/frontend/login.html`，观察界面层分区，并悬停 `form`、`label`、`input`。

状态栏 **知码 · 学习中** 可一键暂停。暂停会清除学习装饰和学习诊断，不会重排原来的 Git、终端或调试面板。

## 本版功能

| 功能 | 实现范围 |
| --- | --- |
| 项目文件树 | 多根工作区；目录懒加载；Python / HTML 文件；忽略依赖目录和符号链接 |
| 文件说明 | 文件顶部说明、侧栏导读；明确标出路径规则推测 |
| 术语 | 52 条内置词条；按语言区分；别名匹配；悬停卡片、搜索和详情 |
| 标注 | 选区 / 当前行添加；查看、编辑、删除；作者、时间；SQLite 独立持久化 |
| 锚点 | 选中文本 + SHA-256；唯一精确匹配后重定位；变化或多处匹配标记失效；手动重新绑定 |
| 职责分区 | Python / HTML Tree-sitter AST、路径规则、路由装饰器模式；5 类色带与可选淡色背景 |
| 中文报错 | 接入已有语言扩展诊断、内置语法解析提示；终端报错可以手动粘贴解释 |
| 修复 | 对明确缺失的 `else / try / finally` 冒号提供预览；检查语法改善、文档版本；确认后修改，可撤销；记录保存在侧栏 |
| 健康提示 | 当前文件的函数长度、控制流嵌套、参数数量、未使用局部变量候选、函数体精确重复候选；HTML 图片 alt 提示 |

## 配置

在设置中搜索 `知码` 或 `zhima`：

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `zhima.enabled` | `true` | 学习模式 |
| `zhima.regionBackground` | `true` | 淡色分区背景；关闭后保留色带 |
| `zhima.functionLines` | `50` | 函数行数参考值 |
| `zhima.nestingDepth` | `4` | 控制流嵌套参考值 |
| `zhima.parameterCount` | `5` | 参数数量参考值；不计 self / cls |
| `zhima.maxFileKB` | `1024` | 自动分析文件大小上限 |
| `zhima.ignoreDirectories` | 依赖、缓存、构建目录 | 目录名称列表 |

命令面板（`Ctrl+Shift+P`）搜索 **知码** 可找到所有操作，包括“查找术语”“解释粘贴的报错”“打开本地数据目录”。

## 数据与隐私

- 标注和修复记录保存在 VS Code 当前工作区的扩展存储目录中的 `notes.sqlite`；不会把标注写进源码。
- 用 **知码：打开本地数据目录** 查看。备份前关闭相关 VS Code 窗口，然后复制数据库文件。
- 标注快照包含你选中的源码，请像管理源码一样管理此数据库。关闭学习模式不会删除它。
- 每个工作区独立存储；同一工作区的窗口写入使用文件锁保护。改变工作区身份或搬迁项目不会自动迁移旧数据库与文件地址。
- 文件读取限制在工作区实际路径内，拒绝越界符号链接；仅分析 `.py` / `.html`。
- 本版没有网络客户端、AI 上传、项目代码执行或沙盒功能。术语、分区和诊断都在本地处理。

## 开发运行

开发需要 **Node.js 22.12+ 和 npm**，普通安装用户不需要 Node.js。源代码采用 TypeScript strict，运行包由 esbuild 构建。依赖中的 Tree-sitter 和 SQLite WASM 会一起打包，安装后离线可用。

```powershell
npm install
npm run check
npm test
npm run build
```

用 VS Code 打开本项目根目录，按 **F5** 选择“运行知码插件（示例项目）”，将在独立扩展开发窗口中打开示例。

持续开发：

```powershell
npm run watch
```

修改后在扩展开发窗口执行“开发人员：重新加载窗口”。

打包：

```powershell
npm run package
```

本仓库同时提供 `pnpm-lock.yaml`，需要锁定依赖版本时使用 `pnpm install --frozen-lockfile`。新版 pnpm 会限制依赖安装脚本；此项目构建不依赖 keytar 或签名工具的安装脚本，不需要批准它们。

真实 VS Code 宿主测试（会使用本项目下独立的 `.test-user` 和 `.test-extensions`，不会改动日常配置）：

```powershell
node scripts/test-vscode.mjs
```

若 VS Code 不在默认安装位置，先设置 `VSCODE_EXECUTABLE` 为 `Code.exe` 的完整路径。验证结果写入 `test-results/integration.json`。

## 当前边界

- 本版健康检查按已打开文件计算，不做全项目后台索引，也不声称覆盖所有缺陷。未使用变量和重复函数体是保守候选；不自动删除代码。
- Tree-sitter 提示语法结构，不提供 Python 完整类型检查。需要更全面的诊断时，可以自行安装 Python / Pylance 等语言扩展；插件会解释其已有诊断。
- 自动修复只有少量明确规则。类型转换、依赖安装等高歧义问题只给建议，不猜测改写。
- 路径与模式匹配只能推测职责，不等于业务语义理解。
- 注释或字符串中的普通术语也可能触发词典解释。词典注明上下文，不把同名词解释当作代码分析结论。
- 本版未实现手动分区、自定义分区规则、模糊锚点、全项目相似度分析、代码地图、项目导览路径、沙盒、知识图谱、AI 或团队同步。
- v0.1.0 是本地安装包，尚未发布 Marketplace。

详细设计和后续接入方向见随项目提供的 `docs/architecture.md`。
