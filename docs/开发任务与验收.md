## 每版完成定义

类型检查与相关核心测试通过 → 独立配置 VS Code 宿主通过 → 从最终 VSIX 解包后再测试，确认离线依赖完整 → 文档版本 / 文件名一致 → 已知限制与未测项写清 → 交付安装包、用户说明、源码。

UI 实验必须标注演示状态。安装助手在目标操作系统执行前，不宣称已经验证所有 Windows 配置；最低 VS Code 版本仍需单独兼容测试。不得把最新宿主通过当成最低版本已验证。
