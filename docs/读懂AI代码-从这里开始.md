# 让知码带你读 AI 写的项目

这一版从你的实际代码出发。你不用先学会所有编程词，也不用先运行项目。

## 第一次只做这三件事

1. 在 VS Code 按 **Ctrl + Shift + P**，输入 **知码**，点 **知码：读懂 AI 写的项目**。
2. 左上角点 **打开 AI 代码文件夹**，选择装着 AI 生成代码的整个文件夹。不是选择某一个文件。新窗口会打开项目阅读室；如果你已经打开了这个项目，知码会直接整理它。
3. 点绿色的 **带我读第一段**。中间是原代码，右边是解释。看过后点 **这段看过了，继续**。

如果 VS Code 原本就打开了你的项目，第 2 步可以跳过。首次使用新版会自动打开阅读室；以后可以从左侧知码的“项目阅读室”再次进入。

## 你会看到什么

**项目全貌**：优先摘录作者写的项目说明，再按页面、处理步骤、说明配置分组。作者没有写用途时，知码会说明尚未找到，不编造业务故事。

**推荐阅读顺序**：优先看页面和明确的启动入口，再看处理文件与其他内容。这是阅读建议，不代表程序一定按这个顺序运行。

**文件之间的连线**：例如 index.html 引用了 app.js，app.js 又引用了 storage.js。点击文件名就能继续阅读。没有连线，不代表两个文件一定没有关系。

**一小段代码**：一次看一个函数、事件或页面块。右边说明接收什么、做什么、交出什么。遇到不懂的词，点下面的小词条展开。

**在编辑器对照**：在旁边打开原文件，并定位这一段。阅读页本身不会改动代码；它显示的是已保存到磁盘的版本。修改后保存，导读会重新整理。

**复制这段的提问**：仍然看不懂时，它会复制一份包含当前代码和具体问题的文字。你可以粘贴到常用的 AI 中继续问。点击只会复制，不会自动发送。

“看过”只是帮你记住读到哪儿，不是考试，也不代表你必须已经学会。源文件变化后，该文件的已看进度会重新计算。

## 安装新版

已经安装旧版：找到本次的 **code-compass-zh-0.4.0.vsix** → VS Code 左侧“扩展” → 右上角 **…** → **从 VSIX 安装…** → 选择它。出现 **重新启动扩展** 时点一下。没有这个按钮通常说明已直接生效。

第一次安装：先全部解压 **知码-0.4.0-新手使用包.zip**，双击 **01-install.cmd**，点 **安装知码**。然后在 VS Code 打开你自己的 AI 项目。你不需要安装 Python、Node.js 或数据库来阅读代码。

包里保留“练习项目”。其中 **idea-notes** 是可阅读的网页便签示例。想先试一下，可以在 VS Code 打开这个文件夹，然后打开知码阅读室。

如果 VS Code 正在更新，先等软件完成更新。看到安装未成功时，可以使用上面的“从 VSIX 安装”方法；不要反复点安装按钮。

## 哪些代码可以看

目前提供 Python、HTML、JavaScript、TypeScript、React JSX / TSX 的结构导读；CSS、JSON、Markdown 可以作为辅助文件阅读。Vue 单文件、Notebook、Java、C++ 等尚未提供结构导读。

每次整理一个本地项目，最多 200 个文件、单文件 256 KB、总读取量约 6 MB、最深 8 层文件夹。忽略隐藏目录、依赖、构建结果与目录链接。达到上限或文件无法读取时，页面会说明；这时只代表已读取的部分。大项目可打开更具体的子文件夹。

每个代码文件最多展示 80 段；长段只显示前 16000 个字符。需要完整内容时点“在编辑器对照”。

## 这一版还有哪些不足

这是本机生成的结构导读，还没有接入在线 AI。它能解释常见语句、页面控件和文件引用；它不能可靠推断复杂业务目的、动态调用、框架约定和所有外部依赖。像“为什么作者这样设计”这类问题，仍需要结合需求或向 AI 进一步提问。

不会自动运行、安装项目依赖或替你修改代码。旧版的 Python / HTML 笔记、报错解释、备份恢复继续保留。JavaScript / TypeScript 的新功能目前集中在阅读室，旧版笔记与修复没有扩展到这些语言。
