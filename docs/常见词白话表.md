# 常见词白话表

不必背下来，遇到不懂的词再来查。技术词不影响你先完成练习。

## def：函数定义

把几步操作放在一起并起个名字，方便以后重复使用。只是写出定义时，这些步骤还不会开始执行。

例如：

```
def greet(name):
    return "你好，" + name
```

## class：类

为一类事物准备的模板。比如 User 描述“用户”应该有什么信息，再按这个模板创建一个个具体用户。

例如：

```
class User:
    def __init__(self, name):
        self.name = name
```

## return：返回值

结束当前函数，并把结果交回调用它的位置。

例如：

```
def add(a, b):
    return a + b
```

## import：导入

把另一个文件或工具提供的功能拿来使用，就像先把需要的工具放到桌上。

例如：

```
from pathlib import Path
```

## self：当前实例

在 Python 类里面，表示“现在正在操作的这个具体对象”。例如 self.name 就是这个对象的名字。

例如：

```
def greet(self):
    return self.name
```

## __init__：初始化方法

创建一个对象时通常会调用的准备步骤，例如先把这个用户的名字保存好。

例如：

```
def __init__(self, name):
    self.name = name
```

## if：条件判断

根据条件选择执行哪一段代码。

例如：

```
if age >= 18:
    print("成年")
```

## for：遍历循环

按顺序取出可迭代对象中的每个元素。

例如：

```
for name in names:
    print(name)
```

## while：条件循环

只要条件成立，就继续执行循环体；要确保存在退出条件。

例如：

```
while count < 3:
    count += 1
```

## break：退出循环

立即结束当前所在的最内层循环。

例如：

```
for item in items:
    if item is None:
        break
```

## try：异常处理

先尝试做一件可能失败的事。配合 except，可以告诉程序失败时该怎么处理，而不是直接停止。

例如：

```
try:
    age = int(text)
except ValueError:
    print("请输入数字")
```

## with：上下文管理

开始使用某样资源，结束后自动做清理。例如读完文件后把文件关上。

例如：

```
with open("demo.txt", encoding="utf-8") as f:
    text = f.read()
```

## async：异步函数

说明这组步骤可以在等待时让出执行机会。await 表示在这里等待某个异步操作的结果；不等于自动让计算变快。

例如：

```
async def load():
    return await get_data()
```

## lambda：匿名函数

临时写一个很短的小函数，不必单独给它起函数名。适合一行能讲清楚的操作。

例如：

```
double = lambda x: x * 2
```

## list：列表

有顺序、可修改的元素集合。append 把一个元素加到列表末尾。

例如：

```
names = []
names.append("小林")
```

## dict：字典

用“名字：内容”保存数据。例如用 name 找到“小林”，不必记住它排在第几个。

例如：

```
user = {"name": "小林"}
print(user["name"])
```

## tuple：元组

一组按顺序放在一起的数据，创建后不能直接换掉其中的元素。

例如：

```
point = (10, 20)
```

## str：字符串

用来表示文本。数字形式的文本仍然不是数字。

例如：

```
age_text = "18"
age = int(age_text)
```

## int：整数

没有小数部分的数字。转换非法文本会产生 ValueError。

例如：

```
age = int("18")
```

## bool：布尔值

只有“是”和“否”两种结果，代码写成 True 和 False，常用来决定下一步做什么。

例如：

```
is_adult = age >= 18
```

## None：空值

表示没有值；它与空字符串、0 和 False 不完全相同。

例如：

```
result = None
```

## len：长度

返回容器中元素的个数或字符串的字符数。

例如：

```
count = len([1, 2, 3])
```

## print：输出

把信息输出到标准输出，常用于学习和观察程序运行。

例如：

```
print("你好，世界")
```

## open：打开文件

得到一个文件对象。使用 with 可以确保及时关闭文件。

例如：

```
with open("demo.txt", encoding="utf-8") as f:
    print(f.read())
```

## route：路由

在 Web 框架中，将 HTTP 路径和方法连接到处理函数；同名词在其他上下文可能有不同含义。

例如：

```
@app.get("/users")
def users():
    return []
```

## request：请求

客户端发给服务端的信息，可能包含路径、参数、请求头和请求体。

例如：

```
name = request.args.get("name")
```

## response：响应

服务端处理请求后返回的状态、数据及响应头。

例如：

```
return {"message": "ok"}
```

## middleware：中间件

一段大家都会经过的公共处理步骤。例如处理请求前，先检查用户是否登录，或记下一条访问记录。

例如：

```
@app.before_request
def auth_middleware():
    check_session()
```

## JWT：JSON Web Token

一种登录凭证的格式。服务用签名检查它有没有被改过，但里面的内容通常可以被读到，不要当作加密保险箱。

例如：

```
Authorization: Bearer <token>
```

## Session：会话

让服务记得“这几次访问来自同一个用户”的机制，像一张临时来访登记卡。具体信息保存在什么地方取决于程序。

例如：

```
session["user_id"] = user.id
```

## html：HTML 文档

用标签描述网页内容及结构。

例如：

```
<!doctype html>
<html lang="zh-CN"></html>
```

## head：文档元信息

包含标题、字符编码和样式引用等，通常不直接显示为页面正文。

例如：

```
<head><meta charset="utf-8"><title>首页</title></head>
```

## body：页面主体

放置用户能看到或交互的页面内容。

例如：

```
<body><h1>你好</h1></body>
```

## div：通用块容器

把相关内容分组；没有特殊语义时可以使用，必要时优先使用语义标签。

例如：

```
<div class="card">内容</div>
```

## span：行内容器

标记一小段文本或行内内容，常用于局部样式。

例如：

```
<p>状态：<span>已完成</span></p>
```

## form：表单

收集用户输入。action 决定提交地址，method 决定提交方法。

例如：

```
<form action="/login" method="post"></form>
```

## input：输入框

收集文本、密码、数字等输入；type 决定控件类型。

例如：

```
<input id="name" name="name" type="text">
```

## label：输入标签

为表单控件提供说明。for 与控件 id 对应，有助于点击和辅助阅读。

例如：

```
<label for="name">姓名</label>
```

## button：按钮

可点击的操作控件。在表单内要明确 type，避免意外提交。

例如：

```
<button type="submit">登录</button>
```

## a：链接

让用户跳转到其他页面或页面中的位置。href 是目标地址。

例如：

```
<a href="/help">帮助</a>
```

## img：图片

显示图片。alt 描述图片内容，供无法看到图片时使用。

例如：

```
<img src="logo.png" alt="项目标志">
```

## script：脚本

引用或包含 JavaScript，为页面添加行为。

例如：

```
<script src="app.js"></script>
```

## style：样式

包含 CSS 样式，用于设置网页的视觉外观。

例如：

```
<style>body { color: #333; }</style>
```

## CSS：层叠样式表

描述网页的布局、颜色和字体等视觉表现。

例如：

```
p { line-height: 1.6; }
```

## fetch：网络请求

JavaScript 提供的请求方法。需要检查响应状态并处理网络失败。

例如：

```
const response = await fetch("/api/users");
```

## id：唯一标识

在同一 HTML 文档中应保持唯一，可供标签关联、样式和脚本定位使用。

例如：

```
<section id="intro">介绍</section>
```

## class：样式类

HTML 中用于给多个元素分组，方便复用 CSS 样式。与 Python 的 class 含义不同。

例如：

```
<div class="card">内容</div>
```

## meta：元数据

描述字符编码、视口等文档信息。

例如：

```
<meta name="viewport" content="width=device-width, initial-scale=1">
```

## section：主题区块

语义标签帮助表达页面的内容结构，便于阅读和辅助技术理解。

例如：

```
<main><section><h2>简介</h2></section></main>
```

## 变量：给一份数据起的名字

就像给抽屉贴标签，以后用这个名字就能找到里面的数据。

例如：

```
name = "小林"
```

## 函数：可以重复使用的一组步骤

把几步操作放在一起并起个名字，需要时再叫它做一次。

例如：

```
def greet(name):
    return "你好，" + name
```

## 参数：交给函数的信息

像点餐时告诉店员“几杯、什么口味”。函数用这些信息做事。

例如：

```
greet("小林")  # 把“小林”交给 greet
```

## 返回值：函数交回来的结果

函数做完后交回的东西。接收者可以保存或继续使用。

例如：

```
message = greet("小林")
```

## 调用：让函数开始做事

写出函数名字并加上括号，就表示请它执行。

例如：

```
greet("小林")
```

## 赋值：把数据交给一个名字

一个等号通常表示把右边的结果保存到左边的名字里，不是判断相等。

例如：

```
age = 18
```

## 字符串：一段文字

代码里通常用引号包住文字。“18”是文字，18 才是数字。

例如：

```
name = "小林"
```

## 条件：决定要不要做的判断

例如“如果下雨，就带伞”。判断结果成立时才做对应的事情。

例如：

```
if age >= 18:
    print("成年")
```

## 循环：重复做一件事

例如依次向名单里的每个人问好。

例如：

```
for name in names:
    print(name)
```

## 缩进：代码前面的空格

Python 用行首空格表示哪些步骤属于同一组。

例如：

```
if True:
    print("这行属于 if")
```

## 注释：写给人看的说明

用来解释代码。普通注释不会作为程序指令执行。

例如：

```
# 这句话写给人看
```

## 标注：你自己写的读书笔记

知码把笔记单独保存，不会把它写进原来的代码。

例如：

```
选中代码 → 右键 → 给这段代码写笔记
```

## 文件夹：装文件的地方

像电脑里的收纳盒。一个代码项目通常由多个文件和文件夹组成。

例如：

```
练习文件夹 / hello.py
```

## 项目：为同一个功能放在一起的一组文件

比如一个登录页面和处理登录的程序，合在一起就是一个小项目。

例如：

```
打开整个练习文件夹，而不只是某一个文件
```

## 工作区：VS Code 当前打开的项目范围

简单理解：你在 VS Code 里打开的那个文件夹；也可以同时打开多个文件夹。

例如：

```
文件 → 打开文件夹
```

## 扩展：给 VS Code 增加功能的小工具

知码就是一个扩展。装上它，VS Code 才会多出中文导读功能。

例如：

```
扩展页 → 从 VSIX 安装
```

## VSIX：VS Code 扩展的安装包

文件名末尾是 .vsix。把它交给 VS Code 安装，不用解压它。

例如：

```
code-compass-zh-0.2.0.vsix
```

## 命令面板：VS Code 的操作搜索框

想做一件事但找不到按钮时，可以打开它并输入操作名称。

例如：

```
按 Ctrl+Shift+P，输入“知码”
```

## VS Code：阅读和编辑代码的软件

可以把它理解为专门用来写代码的笔记本。知码安装在它里面。

例如：

```
先打开 VS Code，再打开练习文件夹
```

## 终端：用文字向电脑发指令的窗口

有些开发操作会在这里输入命令。体验知码的基础功能不需要使用它。

例如：

```
第一次体验不必打开终端
```

## 前端：用户看到和点击的部分

比如网页上的输入框、按钮和文字。

例如：

```
login.html 中的登录表单
```

## 后端：在背后处理请求的程序

例如检查输入、查询数据，再把结果交回页面。

例如：

```
检查用户名是否为空
```

## 数据库：按一定规则保存数据的地方

像可以快速查找的资料柜，例如保存用户名和订单。

例如：

```
查询“编号为 3 的用户”
```

## SQLite：保存在一个文件里的数据库

知码用它保存笔记。使用者不需要安装或启动数据库软件。

例如：

```
notes.sqlite 是知码的笔记数据文件
```

## 接口：程序之间约好的交流方式

像约定“你把名字给我，我把问候语交给你”。Web API 是接口的一种。

例如：

```
请求 /api/users，得到用户列表
```

## 路由：把不同请求交给对应处理代码

像前台分流：查订单去订单窗口，登录去登录窗口。

例如：

```
/login → 处理登录的函数
```

## 业务逻辑：这个产品具体要做的判断和步骤

例如“密码不能为空”或“金额大于 100 才免运费”。

例如：

```
if not password:
    return "请输入密码"
```

## 诊断：检查工具给出的提示

提示可能是错误，也可能只是可以改善的地方。并不代表你操作失败。

例如：

```
图片没有文字说明：可以补一个 alt
```

## 报错：程序告诉你哪里遇到了问题

先看位置和中文原因，一次检查一个问题，不必把全部代码重写。

例如：

```
NameError：某个名字还没有定义
```

## 预览修改：先看看改动会是什么样

左边看原来，右边看准备改成什么。没点“应用”之前，源码不变。

例如：

```
确认对比 → 应用修复 → Ctrl+S 保存
```

## 保存：把当前改动写入文件

编辑器中改完后按 Ctrl+S，改动才会写入磁盘。

例如：

```
Ctrl+S
```

## 撤销：退回上一步编辑

改错了可以按 Ctrl+Z。它撤销代码编辑，不等于删除所有笔记。

例如：

```
Ctrl+Z
```

## 锚点：笔记对应的那段代码

知码记住你选中的文字，尽量在代码移动后找到它；找不准时会请你重新选择。

例如：

```
代码有两份相同内容 → 重新选择笔记位置
```

## AST：程序读出的代码结构

工具把代码拆成“函数、条件、循环”等部分，方便分析。初次使用不需要理解它。

例如：

```
def → 函数；if → 条件
```

## Tree-sitter：帮工具识别代码结构的组件

知码用它辨认函数和标签。它不会替你运行程序，也不保证所有代码都正确。

例如：

```
识别 hello.py 中的函数
```

## API：程序之间交换信息的约定

你按约定给出请求，对方按约定返回结果。使用知码不需要自己调用 API。

例如：

```
查用户：GET /users
```

## MVP：先能使用的第一版

先做最必要的功能，验证好用后再增加其他功能。

例如：

```
先做好读代码和写笔记，再做代码地图
```

## 版本：用来区分不同更新的编号

例如 0.2.0 比 0.1.0 新；更新后功能或说明可能变化。

例如：

```
知码 0.2.0
```

## 依赖：软件需要用到的其他组件

安装包已带上知码运行所需组件，普通使用者不需要逐个安装。

例如：

```
直接安装知码安装包即可
```

## Node.js：运行 JavaScript 的一种环境

主要给开发者使用。安装和使用已打包的知码，不需要你额外安装它。

例如：

```
只有修改插件源码时才需要
```

## npm：开发者安装组件的工具

和 Node.js 配套，给开发者管理项目组件。新手体验流程不需要它。

例如：

```
npm install 是开发步骤，不是使用步骤
```

## 本地：在你自己的电脑上

知码当前版在你的电脑里分析和保存笔记，不把源码发给网络服务。

例如：

```
笔记保存在当前电脑
```

## 云端：在网络上的其他电脑上

某些在线服务在远程服务器上处理数据。知码当前版没有云端功能。

例如：

```
在线 AI 服务属于一种云端服务
```

## 沙盒：限制程序能做什么的运行环境

类似一块受限制的练习区域；安全性取决于实际限制，不是名字叫沙盒就安全。当前版没有运行沙盒。

例如：

```
此功能尚未开放
```

## WASM：一种可被浏览器等环境运行的程序格式

用来运行某些组件。它本身不保证禁网、限时或限制内存。初次使用无需理解。

例如：

```
知码随包带着解析组件
```

## Git：记录代码历史的工具

像给项目保留不同时间的版本，方便比较和找回。知码初次体验不需要 Git。

例如：

```
今天改了什么，可以与昨天比较
```

## JSON：用文字表示结构化数据的格式

可以把它想成一张有字段的资料卡，用“名字：值”记录信息。

例如：

```
{"name": "小林", "age": 18}
```

## ORM：把数据库记录转换成代码对象的工具

例如把“用户表中的一行”变成一个 user 对象，方便代码操作。新手第一轮体验无需使用。

例如：

```
user.name 表示用户的名字
```

## HTTP：网页与服务交换消息的规则

浏览网页时，浏览器通常按它的规则提出请求、接收响应。

例如：

```
GET 表示读取；POST 常用来提交
```

## Token：表示某种凭证的一段文字

某些服务用它判断你是否有访问资格，作用类似门票。不要随意公开自己的凭证。

例如：

```
知码当前版不需要填写 Token
```

## PRD：说明产品要解决什么问题的文档

写清谁会用、要做什么、操作步骤和怎样算完成。

例如：

```
“新用户 5 分钟读懂一个示例”属于产品目标
```

## 哈希：根据内容计算出的识别值

内容发生变化时，识别值通常也会变化。知码用它检查笔记对应的代码。它不是源码加密。

例如：

```
同一段文字 → 同一个识别值
```
