# v0.4：围绕已有 AI 项目的初学者阅读流程

核心目标调整为：选择实际项目 → 认识项目组成 → 找到阅读起点 → 对照代码读一段 → 跟着文件引用继续阅读。练习和查词保留为辅助入口。

## 已实现

- 独立编辑器 Webview，左侧文件路线，中间代码，右侧中文说明；浅色 / 深色 / 高对比色和窄窗适配。
- 同一工作区多个根目录可切换；新选目录在新 VS Code 窗口打开，不替换当前项目。
- Tree-sitter 解析 Python、HTML、JavaScript、TypeScript、TSX；CSS / JSON / Markdown 只提供辅助阅读，不声称完成结构分析。
- 读取真实 README 作为用途说明并标明来源；没有 README 时只描述识别到的文件数量和组成。
- 提取普通导入、部分 require / 动态 import 字面量、HTML src / href 和 Python 模块引用。只连接已扫描到的本地文件，不把外部地址变成可执行链接。
- 按函数、顶层语句、事件回调和 HTML 页面块生成章节；从代码提取参数与 return、常见调用、作者注释。定位行号来自解析树。
- 已看章节保存在工作区状态，按根路径 + 文件路径 + 内容哈希 + 章节 ID 隔离；不把已看当作已掌握。
- 保存文件后重新整理；页面内操作只能引用当前模型中的文件与章节；打开原文件再次检查真实路径边界。
- 提问按钮只复制经过选定的代码片段和固定问题，不调用外部服务。

## 本地对象与命令

ReadingProject：name、description、descriptionSource、files、edges、skipped、limited、readme。ReadingFile：path、language、role、reason、hash、chapters、imports、entry、hasErrors。Chapter：id、title、start、end、code、clipped、summary、input、output、steps、terms。行号内部从 0 起算，界面加 1。

zhima.readProject 打开阅读室；zhima.importProject 打开目录选择器。Webview 消息只允许 ready / refresh / folder / chooseRoot / open / read / ask / help / practice。文件数据只作为纯文本呈现；不渲染项目提供的 HTML，也不运行项目代码。

扫描为异步文件读取，解析仍在扩展宿主。固定读取边界与取消代次避免过时扫描覆盖新模型；每文件最多 80 个章节，长片段截取并明示。不是全项目语义索引器，不保证文件名大小写、别名导入、动态路径、依赖注入与跨包解析全部准确。
