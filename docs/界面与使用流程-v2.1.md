# 知码：界面与使用流程 v2.1

2026-09-24 · 对应插件 v0.2.0 · 用户已选择：一步一步引导，每次只做一件事。

## 已确定的方向

清爽、专业、低饱和；跟随 VS Code 明暗主题；大段阅读留足行距；不使用分数、排名、红黄绿健康仪表盘。入口先说要做什么，专业名称仅出现在可选解释中。

首次打开显示分步页。顶端四步可自由返回；中间突出当前动作；旁边用一个短例子解释词语；底部有“我完成了，下一步”。主流程每步只有一个主要按钮，帮助和查词为次要动作。步骤是用户的阅读进度，不伪装成自动学习评估。

## 页面、状态与跳转

| 状态 | 页面主句 / 主要按钮 | 成功反馈 | 失败 / 退出 |
| --- | --- | --- | --- |
| 未安装 | 安装与开始 / 安装知码 | 安装成功，可打开练习 | 找不到 VS Code 则引导官网下载；保留手动安装路径 |
| 安装完成 | 从这里开始 / 创建我的练习 | 创建独立目录并在新窗口打开 | 取消选目录不写文件；原项目不覆盖 |
| 已有练习 | 读懂一句 / 打开这几行练习代码 | hello.py 出现在旁边，可悬停 def | 文件不存在时给明确错误，不自动猜文件 |
| 看词语 | 中文含义 + 短例子 / 查一查 | 可按中英文检索 | 词典未收录时保留未知，不生成无依据说明 |
| 写笔记 | 写下理解 / 为练习代码写笔记 | 侧栏出现笔记，源码未改变 | 空文本不保存；输入时源码变化则取消 |
| 改错前 | 先看再决定 / 打开改错练习与对比 | 左右对照，等待用户应用 | 无安全规则时只给建议 |
| 改错后 | 已应用，尚未保存 | 可 Ctrl+S 保存 / Ctrl+Z 撤销 | 预览后文档变化则拒绝旧修改 |
| 返回日常阅读 | 六个原生侧栏仍可访问 | 分步页可从命令面板再次打开 | 暂停只停止插件提示，不改用户布局 |

## 文案替换

| 旧说法 | 默认向用户显示 | 可选专业说明 |
| --- | --- | --- |
| 工作区 | 你打开的代码文件夹 | 可同时包含多个文件夹 |
| 标注 | 笔记 | Annotation |
| 锚点失效 | 找不到笔记对应的代码，请重新选择 | 内容变化或匹配不唯一 |
| 代码健康度 | 可以改善的地方 | 静态规则候选，不等于错误 |
| 路由层 | 接收请求 | 路由把请求交给处理函数 |
| 数据层 | 读写数据 | 数据库 / 模型 |
| AST 匹配 | 根据代码结构判断 | AST / Tree-sitter |
| diff | 改前和改后对比 | 差异预览 |
| 安装依赖 | 不出现在普通使用流程 | 留在开发指南 |

词典解释按“它是什么、一个小例子、适用范围”组织。显示英文代码词以便对应源码，同时让中文解释可独立读懂。

## 可访问性与布局验收

- 320px 窄宽度改成纵向排列，不横向挤压；主要操作至少 42px 高。
- Tab 可以到达每个按钮；焦点有清晰边框；键盘可以操作步骤和查词。
- 浅色、深色、高对比主题优先使用 VS Code 主题颜色。
- 成功、失败和状态使用文字，不能只靠颜色表示。
- 常规说明不依赖悬停才能看到；悬停只用于在代码旁按需补充。
- 切步不自动提交笔记或应用代码修改；刷新后保留已选步骤。

## 需要与真实新手验证的事项

邀请 3–5 位第一次使用 VS Code 的用户；不给口头提示，让其完成安装、打开练习、悬停、写笔记和预览修复。记录首次卡住的位置、完成时间、误点和不懂的词。目标是 5 分钟内完成第一段阅读；这是待验证目标，不是已经达到的性能结论。

视觉样稿展示的是流程与布局。真正的文件打开、笔记持久化和修复在插件内完成；不能把样稿的演示反馈算作功能测试通过。
